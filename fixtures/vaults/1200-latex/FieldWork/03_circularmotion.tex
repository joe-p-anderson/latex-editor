Find an example of the following:
\begin{quote}
    An object moving in roughly uniform (i.e. at a constant speed) circular motion. Make sure to discuss the following:
    \begin{enumerate}
        \item What is making it turn? I.e. what is providing the needed centripetal force?
        \item Explain some evidence or why it makes sense to you that were this force to be suddenly taken away, the object would move in a straight line.
    \end{enumerate}
\end{quote}

To receive full credit, this must be an example which you reasonably might have experienced in the course of this week. Also, it must be correct as an example of the above phenomenon.
